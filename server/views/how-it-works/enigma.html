Chapter 1

A key, a wire, a lamp

The Enigma looks like a typewriter, but it prints nothing. Press a key and a lamp lights under a different letter. The operator wrote the lit letters down, and that was the coded message.

Between the key and the lamp, the current takes a winding route: through a plugboard that swaps pairs of letters, through three rotors that each scramble the alphabet with their own wiring, into a reflector that sends it back, and through the rotors and plugboard again by another path.

Try it. Type a message and follow the last letter through the machine.

Chapter 2

The rotors turn

A fixed scramble would be easy to break: it is a simple substitution, solved by counting letters. So every key press turns the right-hand rotor one place before the current flows. Every 26 presses it turns the middle one on, and the middle turns the left.

That changes the whole route, so the same key lights a different lamp almost every time. Type AAAAA on this machine, set to its starting letters, and you get BDZGO.

Try it. Press A again and again, and watch the route move.

Chapter 3

Never itself

At any one position, the machine pairs the letters off: thirteen pairs. If A lights G, then G would light A. That is the reflector's doing, and it made the machine convenient: to decode, the receiver set the same starting letters and typed the coded message in, and the original came out on the lamps.

It had a price. Because the current always comes back by a different wire, no letter can ever be encoded as itself. It looks like a small detail. It was a serious weakness.

Try it. Press a key to step the rotors, and look for a letter joined to itself. There never is one.

Chapter 4

159 million million million

Each day, operators set the machine from a printed sheet: which three of five rotors, in what order; where each started; and which letters to join on the plugboard, usually with ten cables.

Multiplied together that is 158,962,555,217,826,360,000 settings. Nobody could try them one by one. Most of that comes from the plugboard, which is the part that looks least clever.

Try it. Change the number of cables. Ten is close to the most; past eleven the number falls again.

Chapter 5

How it was broken

Polish mathematicians first broke Enigma in the 1930s, and handed what they knew to Britain and France in 1939. At Bletchley Park, the codebreakers used guessed words, called cribs. Military messages were formulaic: a weather report started much the same way every morning.

A crib can only sit where none of its letters matches the letter above it, because no letter is ever itself. That rules out many places straight away. Then Alan Turing's machines, the bombes, raced through the rotor settings to find ones that could turn the crib into the intercepted text.

Try it. Slide the guessed word along the message. Red letters rule a place out.

Sources and notes

The machine in the scene is the three-rotor army Enigma with the real wirings of rotors I, II and III, reflector B, their real notches and the middle rotor's double step. It gives the standard test result: with rings and rotors at A and no cables, AAAAA becomes BDZGO. The message in chapter 5 is an example enciphered on it, not a real intercept.
