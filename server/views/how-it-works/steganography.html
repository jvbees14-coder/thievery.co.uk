Chapter 1

Eight bits of grey

A digital picture is a grid of pixels, and in a simple greyscale picture each pixel's brightness is a number from 0 to 255: eight bits. The first bit is worth 128, the next 64, and so on down to the last, worth just 1.

Flip that last bit and the brightness changes by one step in 255. Nobody can see the difference.

Try it. Change the brightness and compare the two shades, which differ only in the last bit.

Chapter 2

Writing in the last bits

A message is bits too: each letter is a byte of eight. So write the message, one bit at a time, into the last bit of each pixel in turn. About half the pixels change, each by one shade, and the picture looks exactly the same.

Anyone who knows to look reads the last bits back in order and gets the message. Hiding a message where nobody thinks to look, rather than scrambling it, is called steganography.

Try it. Type a message and compare the two pictures.

Chapter 3

Layers of bits

Pull out one bit from every pixel and you get a black-and-white layer. The top layer, the 128s, is a rough outline of the picture. Each layer down carries less of it.

The lowest layer is mostly the grain of the picture, which is why changing it is invisible. A photograph has millions of these bits, room for a long letter.

Try it. Step down through the layers.

Chapter 4

Leaving traces

Invisible isn't undetectable. A message's bits aren't quite like the grain they replace, and careful statistics on the lowest layer can show that something has been written there. Finding hidden messages is called steganalysis.

So people who want both encrypt the message first, which makes its bits look random, and then hide it, spread thinly through a large picture.

Try it. The message's stretch of the lowest layer is shaded. Change the message and watch it grow.
