Chapter 1

A tenth in binary

Computers store numbers in binary. Fractions that are halves, quarters, eighths and so on come out neatly: 0.5 is 0.1 in binary, 0.75 is 0.11.

But a tenth doesn't. In binary it is 0.000110011001100110011… with the 0011 repeating for ever, just as a third is 0.333… in decimal. A computer can only keep so many digits, usually 52, and rounds off the rest.

Try it. Compare 0.5 and 0.75 with 0.1, 0.2 and 0.3.

Chapter 2

0.30000000000000004

So when you type 0.1, the computer stores the nearest number it can hold, which is a shade over a tenth. The same goes for 0.2. Add them and the two small errors add up, then the sum is rounded again, landing one step above the nearest stored value to 0.3.

Ask most programming languages whether 0.1 + 0.2 equals 0.3 and they say no. It's not a bug in the computer: it's working exactly to the standard, IEEE 754, used almost everywhere. That's why money is usually counted in whole pennies.

Chapter 3

Gaps that grow

These are called floating-point numbers because the point floats: a number is kept as a fixed number of significant digits times a power of two. So between each power of two and the next there are always the same count of numbers, and the gaps between them double each time.

Near 1 the gap is tiny, about two parts in ten million billion. Beyond 9 million billion it is 2, so odd numbers can't be stored at all. Precision is relative: always about 16 significant decimal digits.

Try it. See the pattern in a tiny format, then find the gap at a number of your choice.

Chapter 4

When it matters

Small errors can grow. In 1991 a Patriot missile battery in Dhahran, Saudi Arabia, counted time in tenths of a second, stored with 24 bits. Each tenth was off by about a ten-millionth of a second.

After 100 hours running, the clock was 0.34 seconds out. A Scud missile travels over half a kilometre in that time, and the system looked in the wrong place. It failed to intercept a Scud that killed 28 soldiers. The cure was simply to restart the system regularly, which a software update did too late.

Try it. Leave the system running and watch the drift.
