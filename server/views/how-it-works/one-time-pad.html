Chapter 1

A key as long as the message

Write down a string of random letters, as long as your message. Move each letter of the message along the alphabet by the matching letter of the key: A by nought places, B by one, and so on, wrapping round after Z. Send what comes out.

Your friend holds a copy of the same key and moves each letter back. That is the whole cipher, called the one-time pad because the key was printed on pads of paper and each page was torn off and destroyed after use.

Try it. Type a message, and make a new key a few times.

Chapter 2

Unbreakable, really

Most ciphers can be broken with enough time and cleverness. This one can't, and in 1949 Claude Shannon proved it. The reason is simple: for any message of the right length, there is a key that turns the intercepted letters into it.

So the intercept could say anything. An attacker trying keys would find "meet at noon" and "sell the car" and every other message, and no way to tell which was sent. No amount of computing power helps.

Try it. Type a different message: there is always a key that fits.

Chapter 3

Never twice

The guarantee holds only if a key is used once. Send two messages with the same key, and an eavesdropper can subtract one intercept from the other. The key cancels out, leaving one message mixed with the other.

Guess a likely word in one message, slide it along, and wherever the guess is right, the other message appears in plain letters. In the 1940s Soviet clerks under pressure reused some pad pages, and American codebreakers in the Venona project used exactly this to read parts of thousands of messages.

Try it. The first message starts with THE. Slide your guess and watch what the second must say.

Chapter 4

The trouble with keys

A perfect cipher with a terrible catch: you need as much key as you will ever send, it must be truly random, and both sides must hold it, delivered in secret beforehand. When it runs out, somebody has to carry more.

For a few lines that matter enough, people have done it: the teleprinter hotline set up between Washington and Moscow in 1963 used one-time tape. For everyday messages, the key problem is why the world uses other ciphers instead, and public-key cryptography to agree keys between strangers.

Try it. Send messages until the pad runs out.
