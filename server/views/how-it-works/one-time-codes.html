Chapter 1

A secret shared once

When you turn on two-step sign-in with an authenticator app, the website shows a QR code. Inside it is a secret: a random string of letters and digits, here 32 of them. Your phone keeps a copy and so does the website. It is never sent again.

Every six-digit code the app shows afterwards is worked out from that secret and the time. The phone does not need a signal.

Try it. Look inside the QR code.

Chapter 2

Both count the same 30 seconds

Phone and website both know the time. They count how many 30-second steps have passed since the start of 1970, the reference point computers keep time from. That count changes twice a minute, and both sides get the same number without talking.

Websites usually accept the step before and after as well, in case the phone's clock is a few seconds out.

Try it. Watch the count tick over.

Chapter 3

From secret and time to six digits

The secret and the count go into , a hash with a key, which gives 20 bytes that look random. The last half-byte says where to look: take the four bytes starting there, drop the top bit, and keep the last six digits of that number.

The website does exactly the same, and if your six digits match its six digits, you have the secret. Anybody without it gets numbers that look unrelated.

Try it. Step the count forward and back and watch the code change.

Chapter 4

Guessing, and the real risk

A guess is right one time in a million. Sites stop after a handful of wrong tries, so guessing gets almost nowhere.

The danger is being tricked into typing a code into a fake sign-in page, which passes it to the real site within the 30 seconds it lasts. Codes protect against a stolen password, not against a convincing copy of the page. Passkeys, tied to the real website's address, close that gap.

Try it. Change how many tries a site allows.

Sources and notes

The codes are worked out in your browser with real HMAC-SHA-1, exactly as RFC 6238 sets out. The secret is the RFC's own test key (the text 12345678901234567890), so the scene's codes can be checked against the table in the RFC: at 59 seconds after 1970, the six-digit code is 287082. Never use a published secret for a real account.
