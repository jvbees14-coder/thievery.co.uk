Chapter 1

The easy start

An album has 50 stickers to collect, and every packet holds one, picked at random. The first few packets are all new: with nothing collected, any sticker will do.

Half the album fills after about 34 packets. At that rate the whole thing looks like 70 or so away.

Try it. Open packets and watch the album fill, then slow down.

Chapter 2

The long wait for the last one

With 49 of 50 in the album, only one sticker in 50 is any use, so the last one takes 50 packets on average. The one before it takes 25, the one before that about 17.

Each new sticker costs the number in the album divided by the number still missing. Add them all up and a 50-sticker album takes about 225 packets, three times what the start suggested.

Try it. Compare the wait for each new sticker.

Chapter 3

Bigger albums

The total is the size of the album times 1 + ½ + ⅓ + … up to one over the size: a sum called a , which grows slowly but never stops.

Six toys in a cereal box take about 15 boxes. A 600-sticker album takes about 4,200 packets on average: seven times the number of stickers.

Try it. Change the size of the album.

Chapter 4

Swapping with friends

Friends filling the same album can swap their doubles. Pooling everything, two friends need about 165 packets each instead of 225; five need about 115 each; ten, a little over 90.

Swapping helps most with the long wait at the end, because somebody else's spare is usually the one you are missing.

Try it. Add friends and see how many packets each one buys.

Sources and notes

The scene assumes one sticker a packet and every sticker equally common. The figures for a whole album are the exact averages; the swapping figures come from thousands of simulated albums in your browser, assuming the friends pool every packet and swap perfectly. Real packets often hold several stickers, which changes the count of packets but not the shape.
