Chapter 1

A record that can be rewritten

A ledger records who paid whom. Kept as a plain list, anybody who can reach it can change an old line, and nothing on the page shows it.

One fix is to give each page a fingerprint: a of everything written on it. SHA-256 gives 64 hexadecimal digits, and changing a single character changes about half of them.

Try it. Change an entry and watch its fingerprint.

Chapter 2

Each page names the last

A fingerprint on its own can be rewritten along with the page. So each new page also copies out the fingerprint of the page before it, and that copy is part of what its own fingerprint covers.

Now every page vouches for all the pages before it. Keep just the latest fingerprint somewhere safe and you can check the whole ledger.

Try it. Follow the links from each page back to the one before.

Chapter 3

Changes show

Change an old entry and its page's fingerprint changes. The next page still carries the old one, so that link breaks. Mending it means rewriting the next page's copy, which changes that page's fingerprint and breaks the link after it, and so on to the end.

So hiding the change means rewriting every later page, and then the latest fingerprint no longer matches the copy kept safe. Git, the tool most programmers keep their code in, stores its history this way.

Try it. Edit page 2, then rewrite the later pages, and compare the last fingerprint with the one kept safe.

Chapter 4

Making pages costly

A ledger shared among strangers has no safe place to keep the latest fingerprint, and anybody could rewrite all the pages. Bitcoin's answer is to make every page costly to write: a page only counts if its fingerprint starts with a run of zeros, found by changing a spare number, the , until it does.

Each extra zero digit means 16 times as many tries on average: four zeros take about 65,000. Rewriting an old page means redoing the work for it and every page after, faster than everybody else is adding new ones.

Try it. Ask for more zeros and find a nonce.

Sources and notes

Every fingerprint is real SHA-256 of the page's text, nonce and the previous fingerprint, worked out in your browser. Only the first eight digits are shown. The search in chapter 4 is real too; Bitcoin's pages need far more zeros, found by machines built for nothing else.
